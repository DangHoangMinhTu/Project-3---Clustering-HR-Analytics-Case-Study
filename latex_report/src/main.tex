\begin{abstract}
This report applies unsupervised learning to the \emph{HR Analytics Case Study}
dataset, which describes about 4{,}410 employees of a company through
demographic, job, survey and attendance (swipe-in/swipe-out) records.

The goal is to discover naturally occurring employee segments without using
any pre-defined label. We integrate the relational files, clean and engineer
features (including average daily working hours derived from attendance logs),
and compare three clustering algorithms --- K-Means, Hierarchical (Ward)
clustering and DBSCAN --- using the Silhouette score, the Elbow method,
Davies--Bouldin and Calinski--Harabasz indices.

The best model is

The resulting segments are profiled and cross-checked against the
\texttt{Attrition} column (used only for external validation) to derive
practical HR recommendations.

\section{Initial Data Inspection}

Before data preprocessing, an initial inspection was conducted
to understand the structure and quality of all five datasets.
The inspection focused on the number of records, attributes,
data types, missing values, and duplicate records.

\subsection{Dataset Overview}

The HR Analytics dataset consists of five relational files:
\texttt{general}, \texttt{employee}, \texttt{manager},
\texttt{in\_time}, and \texttt{out\_time}.
Each file contains 4,410 records.

Table~\ref{tab:dataset-overview} summarizes the basic
information of the five datasets.

\begin{table}[H]
\centering

\textbf{Criteria}

& \textbf{Employee}

Across the five files, there are 555 attributes in total.
However, the 22,050 records represent the sum of records
across files, not the number of unique employees, since the
same employees are represented in multiple relational files.

\subsection{Initial Data Quality Assessment}

Based on the initial inspection, the following observations
were identified:

\begin{itemize}
    \item All five datasets contain 4,410 records each,
    with a total of 555 attributes.

    \item The datasets contain numerical and string data types,
    requiring appropriate preprocessing techniques.

    \item The \texttt{general} dataset contains 28 missing values,
    while the \texttt{employee} dataset contains 83 missing values.

    \item The \texttt{manager} dataset contains no missing values.

    \item The exact number of missing values in the attendance
    datasets still needs to be determined.

    \item No duplicate records were detected in the five datasets.
\end{itemize}

These findings provide an overview of the data structure
and initial data quality. The next step is to examine the
attendance records, handle missing values, and prepare
suitable features for clustering.
